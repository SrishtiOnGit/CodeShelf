# CodeShelf
A website where you store, organize, and reuse your favorite code snippets in one place.

## Tech Stack :
1. React
2. Django
3. CSS

## The Purpose : 
My Purpose of building CodeShelf was really learning Django.. I had this project in my mind but it requires backend so, I thought I should learn it through a course but don't know I never enjoyed that type of learning I thought to learn it along building and I used AI for concepts steps and more. Though this is my first Django project and working but I feels that I should learn more instead of use AI so I am only shipping my frontend..
